# Fabrication files

One job, the same one as the "Fabrication files" tile in a part's Toolbox in Studio. Do it with
the `pcb` skill: read that skill first and follow it, then do what the person asks:

> Export the fabrication files for the board: gerbers, drill files, the parts list and the placement file. Ask me which fab it is for.

The board is the one the person names, else the one open beside the chat.
Ask which when neither says.

What they get: Gerbers, drill files, the parts list and placement files, ready to upload to a fab.
