# Review before ordering

One job, the same one as the "Review before ordering" tile in a part's Toolbox in Studio. Do it with
the `pcb` skill: read that skill first and follow it, then do what the person asks:

> Review the board before I order it: the fab's limits, decoupling, track widths for the current they carry, and whether every part can be bought. Ask me which fab and what current you need.

The board is the one the person names, else the one open beside the chat.
Ask which when neither says.

What they get: A review against the fab's limits, decoupling, track widths for current and the parts list.
